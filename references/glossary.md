# 术语表（零基础随用随查）

按使用频率排列。每条给：术语 / 人话解释 / 在技能中的含义。

## 循证医学基础

| 术语 | 人话解释 |
|---|---|
| 循证医学 | 治病/下结论不靠拍脑袋，靠"严格实验出来的证据" |
| RCT（随机对照试验） | 把病人随机分两组，一组用疗法、一组不用/用假疗法，比差别 |
| 系统综述 | 把全世界相关研究搜齐，统一评价的综述 |
| Meta 分析 | 系统综述里，把多个实验数据合并算一个总结论的统计方法 |
| 证据等级 | 给证据按"多可信"分 1–5 级，1 最强、5 最弱 |
| 偏倚 | 实验设计不严谨造成的系统性误差，会让结果失真 |
| 置信区间(CI) | 一个范围，真实效果大概率落在这个区间里 |
| 效应量(SMD) | 衡量"效果有多大"的数值，越大效果越强 |

## 炁道 / 中医术语

| 术语 | 人话解释 |
|---|---|
| 炁（气） | 中医/道家说的"生命之气"，推动脏腑功能、经络循行的能量 |
| 元气 | 先天之本，肾所藏的生命原动力 |
| 经络 | 人体气血运行的通道系统，穴位分布在经络上 |
| 穴位（腧穴） | 经络上可施治的特定点，如膏肓穴 |
| 膏肓穴(BL43) | 膀胱经穴，第4胸椎旁开3寸，中医认为"补虚疗劳"要穴 |
| 导引 | 配合呼吸主动运动肢体的锻炼法（调身） |
| 按跷 | 古代对按摩/活动关节等被动调治法的称呼 |
| 导引按跷 | 《内经》记载的治疗法，导引（动+息）+ 按跷（按摩）合用 |
| 行气/吐纳/胎息 | 通过调呼吸来炼气的功法，同一类事物的不同叫法 |
| 三调 | 调身、调息、调心，气功修炼的三个环节 |
| 自主神经 | 管心跳、呼吸、消化等不受意识控制的神经（交感/副交感） |
| 副交感神经 | 自主神经"刹车"面，主管放松、休息、心率变异性升高 |
| 心率变异性(HRV) | 心跳间隔的波动度，反映自主神经平衡，是评估指标 |
| 筋膜 | 包裹肌肉/器官的结缔组织，牵拉可影响体位与神经 |

## 信源 / 核验

| 术语 | 人话解释 |
|---|---|
| 一手来源(信源A) | 直接能打开原文的期刊论文/权威古籍点校本 |
| 二手转述(信源B) | 权威机构/媒体转述一手来源，未直读原文 |
| 待核验(信源C) | 无名网站/自媒体内容，只能当线索，不能当依据 |
| 篇目+版本+页码 | 古籍引用的完整出处格式，缺一样就要标"待考" |
| 待考/存疑 | 没核实到一手出处，不能当定论的节点 |

## 检索

| 术语 | 人话解释 |
|---|---|
| 关键词 | 检索时输入的词；中英各一组可覆盖更多文献 |
| MeSH | 医学主题词，PubMed 的规范检索词，帮搜得更准 |
| 时间窗 | 限定检索哪个时间段（近5–10年 / 不限年代） |
| PICO | 拆问题的口诀：人群、干预、对照、结局 |
