# 古籍溯源方法论（概念源流考据）

用于追溯"炁 / 导引按跷 / 经络 / 元气"等炁道核心概念的历史源流。溯源不是检索清单，是**考据**：目标是把一个概念还原到"最早出处 → 历代演变 → 异名同实 → 学术谱系 → 传承脉络"，每一步都可回退到一手权威版本。

## 溯源工作流

### 第 1 步：确立概念的"核心问题"
- 这个概念最早出现在哪部典籍？
- 历代（先秦→汉→唐→宋→明清→近现代）其含义如何演变？
- 有哪些异名/近名？（例：导引=按跷=挢引=案杌；行气=吐纳=胎息）
- 谁在传承、哪条谱系线？

### 第 2 步：确立权威版本底本（硬性）
- 只用**权威点校本**：人民卫生出版社、中华书局点校本、《中华医典》检索版。
- 禁以网络转述、营销号引文、无版本二手百科为溯源依据。
- 每个引用格式：**书名 · 篇名 · 版本 · 页码**；无法确定版本即标"待考"。

### 第 3 步：按时代分段检索
- 分段：先秦（《内经》《庄子》）、汉（《行气玉佩铭》、马王堆《导引图》、《史记》）、唐（王冰注、孙思邈）、宋明（功法汇编）、近现代（文献整理与教科书）。
- 每个时代单独检索与核对，避免混淆"最早出处"与"后世转述"。

### 第 4 步：异名考辨与谱系梳理
- 列出同一概念的不同叫法与所指（例：炁 vs 气；导引 vs 按跷 vs 行气）。
- 考辨：这些异名是同指、近指，还是被后世误用。
- 谱系：记录"谁承谁"的传承线索（例：《内经》"导引按跷" → 王冰注 → 后世气功学）。

### 第 5 步：时间线整理
- 按时代排序输出"概念流变时间线"，标注每站的一手出处。
- 这是溯源报告的主骨架。

### 第 6 步：双重核验
- 每条溯源结论回底本核对；转述标"据转述·待核对"。
- 无法回退一手出处的节点，在报告中显式标"存疑/待考"，不臆断。

## 溯源输出结构（报告骨架）

1. 概念定义与核心问题
2. 最早出处（一手条文 + 版本页码）
3. 历代演变（时间线，每站一手出处）
4. 异名与同实考辨
5. 学术谱系与传承
6. 待考项与证据缺口（明确列出未核实的节点）

## 溯源纪律

- 版本优先于名气：任何网络高传播的古籍引文，未回底本前一律"待考"。
- 区分"概念源流"与"临床疗效"：溯源回答"从哪来、怎么演变"，疗效才回答"有没有效"。
- 溯源报告按 [references/whitepaper.md](references/whitepaper.md) 可直接升级为白皮书章节。
