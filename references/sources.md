# 中英信源映射 + 权威源白名单 / 低质源降级

按"语种 × 证据类型 × 可信度"选源。**权威源准入是本技能第 5 步核验的前提**：凡是能进白皮书正文的结论，来源必须落在白名单 A 档；B/C 档只能作背景或过渡，且须显式降级标注。

## 信源可信度分级（三级）

| 档位 | 定义 | 能否进白皮书正文 | 标注写法 |
|---|---|---|---|
| **A · 权威一手** | 期刊论文（有 DOI/PMID，可打开原文）、权威点校古籍（人民卫生/中华书局/《中华医典》）、政府/机构文件、数据库条目原文 | 可以，作为权威依据 | `信源A·一手` |
| **B · 权威转述** | 权威机构/高校/主流媒体对一手来源的转述或综述，未直读原文 | 可作支撑，须注明"据转述" | `信源B·转述` |
| **C · 低质待核验** | 无名网站、自媒体、营销号、无版本依据的网络引文、二手百科 | 禁止作为权威依据；仅作线索，须核验后升级或弃用 | `信源C·待核验` |

## 权威源白名单（A 档）

| 来源 | 语种/类型 | 推荐工具 | 说明 |
|---|---|---|---|
| PubMed (MEDLINE) 带 PMID/DOI | 英文循证 | `scholar_search` / `general_search` / `web_fetch` | 临床与机制首选 |
| Cochrane Library | 系统综述 | `general_search` + `web_fetch` | 干预性最强证据 |
| 中国知网 CNKI 核心/期刊 | 中文期刊/学位论文 | `general_search`+`web_fetch`，需全文走浏览器 | 中文主力，注意区分来源期刊等级 |
| 万方 / 维普 正规期刊 | 中文期刊 | `general_search`+`web_fetch` | 学位论文与回溯 |
| 中国生物医学文献服务系统 (CBM/SinoMed) | 中文医学文献 | `general_search` / 浏览器 | 权威中文医学索引 |
| 《中华医典》、人民卫生/中华书局点校本 | 古籍权威版本 | 浏览器 / 权威电子库 | 古籍溯源唯一权威底本 |
| 国家中医药管理局、国家体育总局健身气功中心 | 政策/功法规范 | `general_search` | 权威机构文件 |
| `seed_medical_search` | 指南/药物/医院/医生 | 直接调用 | 循证指南类 |

## 低质源示例（C 档，须降级）

- 无名百科类（抖音百科等 UGC 百科）、豆丁网/道客巴巴文档分享、39健康/复禾健康等营销健康站、无出处的微信公众号/营销号文章。
- 判断：**无作者身份、无期刊/版本信息、无可回退原文链接**的一律按 C 档处理。

## 古籍溯源专用底本

- 以《中华医典》检索版 + 人民卫生出版社 / 中华书局点校本为准。
- 引用格式：**书名 · 篇名 · 版本 · 页码**（如《素问·异法方宜论篇》，人民卫生出版社 1963 年版，页 84）。
- 网络转述古籍条文时，一律先回底本核对，不核对则标"据转述，待考"。

## 检索纪律

- 一次并行 query ≤3；不重复检索。
- 命中先标**证据等级 + 信源档位**，再进入产出。
- 证据不足就补检索；信源 C 的内容必须核验或弃用，不靠"应该/大概"支撑结论。
