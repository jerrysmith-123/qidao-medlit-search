# 炁道智慧体系：四层检索框架与落地

检索前先确定命中的层，取该层的检索关键词模板与落地动作，把"资料搜寻"和"体系落地"串成闭环。

## 体系四层结构

```
理论层 Theory  →  机制层 Mechanism  →  实践层 Practice  →  证据层 Evidence
 (炁/经络/脏腑)    (解剖生理/神经通路)    (元炁操/穴位/手法)    (文献/分级/经验核验)
```

## 各层检索关键词模板（中英双轨）

### 理论层（Theory）——炁、经络、脏腑、天人相应
- 中文：炁 / 元气 / 经络 / 导引 / 气功 / 脏腑 / 天人相应 / 藏象
- 英文：qi / yuan qi / meridian / daoyin / qigong / zang-fu / correspondence
- 信源：古籍经典 + 现代中医理论综述
- 落地动作：汇总经典条文与现代理论定义，形成理论层文档与术语表。

### 机制层（Mechanism）——解剖生理、神经通路、自主神经
- 中文：穴位 神经支配 / 迷走神经 / 三叉神经 / 枕颈交界 / 筋膜 / 心率变异性 / 自主神经
- 英文：acupoint nerve / vagus nerve / trigeminal nerve / cervicomedullary / myofascial / heart rate variability / autonomic nervous
- 信源：PubMed、Cochrane（机制研究、RCT）
- 落地动作：为每项核心主张建立机制解释，标注证据等级，附解剖生理学论述。

### 实践层（Practice）——元炁操、导引、取穴、推拿手法
- 中文：元炁操 / 导引术 / 功法 / 穴位按摩 / 推拿 / 特定穴 / 膏肓
- 英文：daoyin exercise / qigong exercise / acupressure / tuina / acupoint / BL43 (Gaohuang)
- 信源：临床观察、RCT、中文中医库、古籍手法
- 落地动作：整理功法/手法操作要点，与机制层、证据层对应，产出教学与实操材料。

### 证据层（Evidence）——文献、证据分级、临床经验核验
- 中文：循证 / 系统评价 / Meta分析 / 随机对照试验 / 临床经验 验证
- 英文：systematic review / meta-analysis / randomized controlled trial / clinical evidence
- 信源：Cochrane、PubMed、CNKI
- 落地动作：持续维护证据库（证据分级摘要 + 结构化清单），追踪"临床经验 → 文献核验"的差距清单。

## 落地流程（一次完整落地）

1. 从用户当前需求定位层（核验某个临床经验 → 证据层 + 机制层；建教学材料 → 实践层 + 理论层）。
2. 取对应层关键词模板做中英双轨检索。
3. 按证据分级标注每条结论。
4. 把结果写入对应层文档，四层合并成一份体系落地文档。
5. 交付前回读：每层内容有来源、证据等级正确、层间逻辑自洽。
