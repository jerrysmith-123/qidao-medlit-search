# 炁道智慧体系：四层检索框架 + 溯源入口

检索前先确定命中的层与任务类型，取对应关键词模板与落地动作。四层框架 + 溯源维度共同支撑"资料搜寻、体系落地、概念溯源"。

## 体系四层结构

```
理论层 Theory  →  机制层 Mechanism  →  实践层 Practice  →  证据层 Evidence
 (炁/经络/脏腑)    (解剖生理/神经通路)    (元炁操/穴位/手法)    (文献/分级/经验核验)
```

溯源（概念源流）是贯穿四层的**第五维度**，见 [references/origin-tracing.md](references/origin-tracing.md)。

## 各层检索关键词模板（中英双轨）

### 理论层（Theory）——炁、经络、脏腑、天人相应
- 中文：炁 / 元气 / 经络 / 导引 / 气功 / 脏腑 / 天人相应 / 藏象
- 英文：qi / yuan qi / meridian / daoyin / qigong / zang-fu / correspondence
- 信源：权威点校古籍（A）+ 现代中医理论综述
- 落地：理论层文档与术语表；如需溯源 → 转 origin-tracing

### 机制层（Mechanism）——解剖生理、神经通路、自主神经
- 中文：穴位 神经支配 / 迷走神经 / 三叉神经 / 枕颈交界 / 筋膜 / 心率变异性 / 自主神经
- 英文：acupoint nerve / vagus nerve / trigeminal nerve / cervicomedullary / myofascial / HRV / autonomic nervous
- 信源：PubMed、Cochrane（A 档）
- 落地：为核心主张建立机制解释，标证据等级，附解剖生理论述

### 实践层（Practice）——元炁操、导引、取穴、推拿手法
- 中文：元炁操 / 导引术 / 功法 / 穴位按摩 / 推拿 / 特定穴 / 膏肓
- 英文：daoyin exercise / qigong exercise / acupressure / tuina / acupoint / BL43 (Gaohuang)
- 信源：临床观察、RCT、中文中医库、古籍手法
- 落地：整理功法/手法操作要点，与机制层、证据层对应

### 证据层（Evidence）——文献、证据分级、临床经验核验
- 中文：循证 / 系统评价 / Meta分析 / 随机对照试验 / 临床经验 验证
- 英文：systematic review / meta-analysis / RCT / clinical evidence
- 信源：Cochrane、PubMed、CNKI（A 档）
- 落地：维护证据库（分级摘要 + 清单），追踪"临床经验 → 文献核验"差距

## 落地流程（一次完整落地）

1. 从需求定位任务（核验 → 证据层+机制层；建教学 → 实践层+理论层；溯源 → origin-tracing）。
2. 判定受众（零基础 → 先给通俗层）。
3. 取对应层关键词做中英双轨检索，标**证据等级 + 信源档位**。
4. 过**引用真实性核验**（见 evidence-grading.md）。
5. 双层输出并合并成体系文档 / 白皮书（见 whitepaper.md）。
6. 交付前回读：每层内容有来源、等级正确、层间自洽、无法回退的节点已标待考。
